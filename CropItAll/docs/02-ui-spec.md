# UI-спецификация CropItAll

## Общие принципы
- Только портретная ориентация.
- Светлая и тёмная темы (по системным настройкам).
- Крупные кнопки, читаемый текст.
- Прогрессивное раскрытие: кнопки появляются по мере прохождения шагов.
- Все строки — через `R.string`.

## Цвета
- Основной: бирюзовый `#0F9D8E`
- Акцент: оранжевый `#FF9F43`
- Фон светлый: `#F5F7FA`
- Фон тёмный: `#121212`

## Главный экран (MainActivity)

### Первый запуск (режим обучения)
- **И1:** «Шаг 1 из 3: выберите папку со скриншотами».
- Кнопка «Выбрать папку» — активна.
- Поле ввода названия — серое, неактивное.
- Кнопка «FRAME» — серая, неактивная.

### После выбора папки
- **И1:** «Шаг 2 из 3: введите название вебинара».
- Поле ввода — активно.
- Кнопка «FRAME» — серая, пока имя не введено.

### После ввода имени
- **И1:** «Шаг 3 из 3: нажмите FRAME, чтобы перейти к обрезке».
- Кнопка «FRAME» — активна.

### Повторные запуски
- Режим обучения не показывается.
- Все элементы управления активны.
- **И2:** журнал последней операции.

### Переключение шагов
- Управляется внутри `MainViewModel`.
- Состояние определяется по `folderUri` и `baseName`.

### Неактивные элементы
- Серый цвет, полупрозрачность, не нажимаются.
- **Без иконки замка** (ложная ассоциация с платным контентом).

## Экран обрезки (CropActivity)

### Расположение элементов (сверху вниз)
1. **Верхняя панель:** кнопка «Crop it ALL» на всю ширину.
    - При первом показе: «Crop it ALL — обрезать все скрины по этому шаблону» (две строки).
    - После первого использования: «Crop it ALL» (одна строка).
2. **Центральная область:** изображение (fitCenter) + CropOverlayView.
3. **Ряд навигации:** `<<` `<` `>` `>>` (четыре кнопки в ряд).
4. **Нижняя панель:** две кнопки.
    - Левая: «ГОТОВО» (половина ширины).
    - Правая: «Crop it» (половина ширины).

### Поведение навигации
- `<<` — к первому изображению. Неактивна на первом.
- `<` — к предыдущему. Неактивна на первом.
- `>` — к следующему. Неактивна на последнем.
- `>>` — к последнему. Неактивна на последнем.
- Неактивные кнопки — бледные, не нажимаются.

### Рамка (CropOverlayView)
- При первом запуске охватывает весь слайд.
- Редактируется: перетаскивание целиком, растягивание за углы и стороны.
- Углы и стороны визуально выделены.
- Область вне рамки затемнена на 50%.
- Сетка «правила третей» не показывается.
- Рамка **НЕ сбрасывается** при смене изображения.
- Рамка сохраняется в DataStore и восстанавливается при следующем запуске.

### Кнопки обрезки
- «Crop it» — обрезать текущий, перейти к следующему.
    - На последнем слайде: сообщение «Это последний скрин. Обрезка завершена» и возврат на главный экран.
    - Кнопки «Crop it» и «Crop it ALL» видны только после выделения области.
- «Crop it ALL» — диалог «Обрезать все N файлов с текущей областью?» (Да/Нет).
    - Обрабатывает файлы **от текущего до конца списка**.
    - Пропущенные ранее (до текущего) — не трогаются.
    - Во время обработки — overlay с `ProgressBar` и текстом «Обработка X из Y».
    - Кнопка «Отмена» доступна.
    - После завершения — возврат на главный экран со статистикой.
- «ГОТОВО» — диалог «Выйти из обрезки или начать новый вебинар?».
- Системный «Назад» — вызывает тот же диалог, что и «ГОТОВО».

### Диалог «Выход из обрезки» (по кнопке «ГОТОВО» и системной «Назад»)

**Заголовок:** «Вебинар: <текущее_имя>»
**Текст:** «Выйти из обрезки или сменить вебинар?»
**Кнопки:**
- **«Выйти»** — закрыть `CropActivity`, вернуться на главный экран.
  Имя вебинара и папка сохраняются.
- **«Сменить вебинар»** — открыть диалог «Новый вебинар» (см. ниже).
- **«Отмена»** — закрыть диалог, продолжить обрезку.

**ВАЖНО (будущая версия):** после реализации `CropViewModel` с подсчётом
обработанных файлов — заголовок станет «Вебинар: <имя> (обработано X из Y)».
Реализуем позже, когда появится логика обрезки.

### Диалог «Новый вебинар» (открывается из диалога «Выход»)

**Заголовок:** «Новый вебинар»
**Текст:**
```
Текущий слайд (№<N>) начнёт новый вебинар.
Предыдущие слайды сохранены в папке <старое_имя>.

Введите название нового вебинара:
```
**Поле ввода:** `EditText` с текущим именем вебинара (автофокус + курсор в конце).
**Кнопки:**
- **«Отмена»** — закрыть диалог, ничего не менять.
- **«Начать»** — сохранить новое имя, обновить `currentWebinarName`,
  закрыть диалог. Текущий слайд становится первым в новой папке.

**Валидация:** если поле пустое — не закрывать диалог, показать Toast
«Введите название вебинара».

**Логика:**
- Диалог «Новый вебинар» вызывается **только из `CropActivity`**.
- Пользователь обрабатывает несколько вебинаров в одной исходной папке,
  не выходя на главный экран.
- Для смены исходной папки — использовать «Выйти» → главный экран → выбрать папку заново.

### Пропуск слайда
- Нажатие `>` без «Crop it» = пропуск.
- Файл остаётся в `P_SRC` нетронутым.

## Будущее развитие: MassCropActivity

- Отдельный экран для массовой обрезки (вместо overlay).
- Визуализация процесса очистки памяти:
    - Левый прямоугольник: уменьшается по мере удаления исходников.
    - Правый прямоугольник: растёт по мере создания обрезанных файлов.
    - Стрелка между ними (слева-направо).
    - Ширина каждого — 30% экрана, отступы 10% сверху/снизу.
- Замена overlay в `CropActivity` на переход в `MassCropActivity`.
- Изменения локальные: новый экран + новый ViewModel + одна строка в CropActivity.
